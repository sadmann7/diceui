`@diceui/pptx` pulls in `@diceui/pptx-core` automatically. The thumbnail rail collapses below 768px behind a toggle, which is why this item also depends on `button` and `use-mobile`. The primitives themselves use a `render` prop (not `asChild`) even in a Radix project.

## Layout

Import the parts, and compose them together.

```tsx
import {
  Presentation,
  PresentationContent,
  PresentationError,
  PresentationLoading,
  PresentationSelection,
  PresentationSlide,
  PresentationThumbnailList,
  PresentationViewport,
} from "@/components/ui/presentation";

return (
  <Presentation>
    <PresentationThumbnailList />
    <PresentationContent>
      <PresentationLoading />
      <PresentationError />
      <PresentationViewport>
        <PresentationSlide>
          <PresentationSelection />
        </PresentationSlide>
      </PresentationViewport>
    </PresentationContent>
  </Presentation>
)
```

Pass a `File`, `Blob`, `ArrayBuffer`, or `Uint8Array` to `file` on `Presentation`. There is no toolbar in this item — toolbars are assembled around the primitives.

Without children, `PresentationSelection` renders its overlay parts with a default look. Compose them to restyle the overlay or leave parts out.

```tsx
<PresentationSelection>
  <PresentationSelectionBox>
    <PresentationResizeHandle />
    <PresentationRotateHandle />
  </PresentationSelectionBox>
  <PresentationSnapGuide />
  <PresentationMarquee />
</PresentationSelection>
```

## Examples

### Editing

Load with `readOnly={false}` and place `PresentationSelection` inside `PresentationSlide` to move, resize, rotate, and edit text. Undo and redo shortcuts are opt-in via `undoRedoShortcuts`. Drag thumbnails to reorder slides.

The toolbar uses `useSelection` to insert text boxes and shapes, format text, and arrange or delete shapes. It is marked with `data-pptx-keep-selection` so pressing it keeps the selection and text editing.

This example also uses `PresentationZoomSelect`, a companion control built with `useZoom` and `select`. Install it with `@diceui/presentation-zoom-select`.

### PresentationSelection

PowerPoint-style editing overlay. Enables drag-to-move, resize, rotation, snapping, inline text editing, multi-select, copy and paste, and keyboard shortcuts. Renders nothing unless the presentation was loaded with `readOnly={false}`.

Must be placed inside `PresentationSlide`.

| Action | Behavior |
| --- | --- |
| Click shape | Select |
| Click selected shape, double-click, or type | Edit text |
| Drag shape | Move (Shift locks one axis, Alt skips snapping) |
| Drag resize handle | Resize (Shift on a corner keeps the aspect ratio) |
| Drag rotate handle | Rotate (Shift steps by 15°) |
| Shift/Ctrl/Cmd + click | Toggle a shape in the selection |
| Drag empty canvas | Marquee select |

Moving and resizing snap to the slide's edges and center and to other shapes. Set `snapping={false}` to turn it off, or `snapThreshold` to change the distance. A text box left empty is removed once editing moves elsewhere.

### useSelection

Reads the editing overlay's selection and its text formatting, and runs commands on it. Works anywhere under `PresentationProvider` or `Presentation`, so a toolbar can sit outside the slide.

Pressing a toolbar would normally clear the selection and end text editing. Mark the toolbar, and the content of its popovers and menus, with `data-pptx-keep-selection` (exported as `KEEP_SELECTION_ATTRIBUTE`).

```tsx
import { useSelection } from "@diceui/pptx";

function BoldButton() {
  const { textStyle, setTextStyle } = useSelection();

  return (
    <button
      data-pptx-keep-selection=""
      aria-pressed={textStyle?.bold ?? false}
      disabled={!textStyle}
      onClick={() => void setTextStyle({ bold: !textStyle?.bold })}
    >
      Bold
    </button>
  );
}
```

Use `anchor` to position a floating toolbar over the selection, and show it while `mode` is `"selected"` or `"text"`.
