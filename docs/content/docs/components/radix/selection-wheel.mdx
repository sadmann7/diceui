## Layout

Import the parts, and compose them together.

```tsx
import {
  SelectionWheel,
  SelectionWheelTrigger,
  SelectionWheelContent,
  SelectionWheelIndicator,
  SelectionWheelItem,
  SelectionWheelLabel,
} from "@/components/ui/selection-wheel";

return (
  <SelectionWheel>
    <SelectionWheelTrigger />
    <SelectionWheelContent>
      <SelectionWheelIndicator />
      <SelectionWheelItem value="sword" label="Sword" />
      <SelectionWheelItem value="axe" label="Axe" />
      <SelectionWheelLabel />
    </SelectionWheelContent>
  </SelectionWheel>
)
```

Items are spread evenly around the circle in DOM order, starting at the top. Pointing anywhere in a slice highlights it, so you don't have to hit the icon itself. Releasing or clicking picks the highlighted item. Pointing at the center picks nothing.

## Examples

### Hold to Pick

Add a `SelectionWheelTrigger` to open the wheel as an overlay around the pointer. Press the trigger, drag toward an item and release to pick it, like a game. A quick tap keeps the wheel open so you can click or use the keyboard instead. Opening with the keyboard, or with `open` or `defaultOpen`, centers the wheel on the trigger.

<ComponentTabs name="selection-wheel-trigger-demo" />

### Open at a Point

Wrap a region in `SelectionWheelArea` to open the wheel wherever the user right-clicks, like a pie menu. Where right-clicks fire on press, as on macOS, holding the button, dragging and releasing picks too. Set `openKey` to open it at the pointer while a key is held, then release the key to pick, like a game's weapon wheel.

<ComponentTabs name="selection-wheel-area-demo" />

### Nested

Wrap a `SelectionWheelSubTrigger` and a `SelectionWheelSubContent` in a `SelectionWheelSub` to group items behind one slice. Picking the sub trigger swaps the ring for its items, centered on the same spot. Press `Escape` or `Backspace`, or click the center, to go back. In a radio wheel, the sub trigger shows as checked when the selected value is inside it. Values must be unique across all levels.

<ComponentTabs name="selection-wheel-nested-demo" />

### Actions

Set `type="menu"` when items run actions instead of holding a value. The wheel renders as a menu, and each item's `onSelect` fires when it's picked.

<ComponentTabs name="selection-wheel-menu-demo" />

### Controlled

Use `value` and `onValueChange` to control the selected item.

<ComponentTabs name="selection-wheel-controlled-demo" />

### Sizing

Set `size` for the diameter and `deadZone` for the radius of the center area. The `SelectionWheelLabel` fills the dead zone, so both affect how much room the label has.

```tsx
<SelectionWheelContent size={320} deadZone={56}>
  {/* items */}
</SelectionWheelContent>
```

## Accessibility

The wheel is a `radiogroup` of `radio` items, or a `menu` of `menuitem`s when `type="menu"`. Focus stays on the wheel and `aria-activedescendant` points at the highlighted item, so screen readers announce its label and position, for example "Sword, 2 of 8". Give icon-only items a `label`.
