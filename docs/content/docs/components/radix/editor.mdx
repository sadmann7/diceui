## Layout

Import the parts and compose them together.

```tsx
import {
  Editor,
  EditorBlock,
  EditorBlockSelect,
  EditorBubbleMenu,
  EditorCharacterCount,
  EditorContent,
  EditorLink,
  EditorMark,
  EditorRedo,
  EditorSlashMenu,
  EditorToolbar,
  EditorToolbarSeparator,
  EditorUndo,
} from "@/components/ui/editor";

return (
  <Editor>
    <EditorToolbar>
      <EditorUndo />
      <EditorRedo />
      <EditorToolbarSeparator />
      <EditorBlockSelect />
      <EditorMark mark="bold" />
      <EditorLink />
      <EditorBlock block="bulletList" />
    </EditorToolbar>
    <EditorContent />
    <EditorBubbleMenu>
      <EditorMark mark="bold" />
      <EditorLink />
    </EditorBubbleMenu>
    <EditorSlashMenu />
    <EditorCharacterCount />
  </Editor>
);
```

The editor comes with headings, lists, task lists, quotes, code blocks, dividers, links, undo and redo. Add more [Tiptap extensions](https://tiptap.dev/docs/editor/extensions/overview) with `extensions`.

## Content

`format` sets what `value`, `defaultValue` and `onValueChange` use:

| Format     | Value                                                  |
| ---------- | ------------------------------------------------------ |
| `html`     | An HTML string, or `""` when the editor is empty       |
| `markdown` | A Markdown string                                      |
| `json`     | Tiptap's [`JSONContent`](https://tiptap.dev/docs/editor/core-concepts/schema) |

HTML from users can contain anything, so sanitize it before rendering it outside the editor.

The editor mounts in the browser, so the content area is empty until it loads. Style `[data-pending]` to show a loading state:

```tsx
<EditorContent className="data-pending:animate-pulse data-pending:bg-muted" />
```

## Slash commands

`EditorSlashMenu` lists a command for each block and a divider. Pass a function to `items` to change them, like adding descriptions or your own commands.

```tsx
<EditorSlashMenu
  items={(items) => [
    ...items,
    {
      value: "date",
      label: "Today's date",
      keywords: ["now"],
      onSelect: ({ editor, range }) =>
        editor
          .chain()
          .focus()
          .deleteRange(range)
          .insertContent(new Date().toDateString())
          .run(),
    },
  ]}
/>
```

## Custom controls

`useEditorInstance` returns the Tiptap editor, or `null` until it's created, to build your own controls.

```tsx
import { useEditorInstance } from "@/components/ui/editor";

function ClearFormatting() {
  const editor = useEditorInstance();

  return (
    <Button
      onMouseDown={(event) => event.preventDefault()}
      onClick={() => editor?.chain().focus().unsetAllMarks().run()}
    >
      Clear formatting
    </Button>
  );
}
```

## Accessibility

The editable area is a multiline `textbox`. The toolbar and bubble menu follow the [Toolbar pattern](https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/), and the slash menu is a `listbox` the textbox points to with `aria-activedescendant`, so focus stays in the text.
