## Layout

Import the parts and compose them together.

```tsx
import {
  CommandStack,
  CommandStackBreadcrumb,
  CommandStackEmpty,
  CommandStackGroup,
  CommandStackInput,
  CommandStackItem,
  CommandStackList,
  CommandStackPage,
  CommandStackShortcut,
} from "@/components/ui/command-stack";

return (
  <CommandStack>
    <CommandStackBreadcrumb />
    <CommandStackInput />
    <CommandStackList>
      <CommandStackEmpty />
      <CommandStackPage value="root">
        <CommandStackGroup>
          <CommandStackItem page="projects">
            <CommandStackShortcut />
          </CommandStackItem>
        </CommandStackGroup>
      </CommandStackPage>
      <CommandStackPage value="projects">
        <CommandStackItem />
      </CommandStackPage>
    </CommandStackList>
  </CommandStack>
)
```

## Examples

### Popover

Put the stack in a popover for nested menus, such as a filter menu where each filter opens its options. Set `selectionMode` on a page to make its items toggleable, and control the selection with `value` and `onValueChange`. The stack goes back to the root page whenever the popover closes.

<ComponentTabs name="command-stack-popover-demo" />

### Command Palette

Render the stack inside `CommandDialog` to build a command palette. This example opens with <Kbd>⌘ J</Kbd>, since <Kbd>⌘ K</Kbd> opens the docs search.

<ComponentTabs name="command-stack-dialog-demo" />

### Workspace

Pages can nest as deep as you need, and items can hold any layout.

<ComponentTabs name="command-stack-workspace-demo" />

### Async

Load a page's items when it opens. `useCommandStack` gives access to the active page, and `CommandStackLoading` hides the empty state while items load.

<ComponentTabs name="command-stack-async-demo" />

### useCommandStack

Reads and changes the stack's pages from any component inside it. It returns `pages`, `activePage`, `search`, `value`, `pushPage(page)`, `popPage()`, `setPages(pages)` and `setValue(value)`.

```tsx
import { useCommandStack } from "@/components/ui/command-stack";

function OpenSettings() {
  const { pushPage } = useCommandStack();

  return (
    <CommandStackItem onSelect={() => pushPage("settings")}>
      Settings
    </CommandStackItem>
  );
}
```

## Accessibility

The input keeps focus while you move between pages. The breadcrumb is a labelled navigation landmark that marks the current page, and opening a page announces its label to screen readers.
