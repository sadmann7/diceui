## Layout

Import the parts and compose them together.

```tsx
import {
  CommandPalette,
  CommandPaletteBreadcrumb,
  CommandPaletteEmpty,
  CommandPaletteGroup,
  CommandPaletteInput,
  CommandPaletteItem,
  CommandPaletteList,
  CommandPalettePage,
  CommandPaletteShortcut,
} from "@/components/ui/command-palette";

return (
  <CommandPalette>
    <CommandPaletteBreadcrumb />
    <CommandPaletteInput />
    <CommandPaletteList>
      <CommandPaletteEmpty />
      <CommandPalettePage value="root">
        <CommandPaletteGroup>
          <CommandPaletteItem page="projects">
            <CommandPaletteShortcut />
          </CommandPaletteItem>
        </CommandPaletteGroup>
      </CommandPalettePage>
      <CommandPalettePage value="projects">
        <CommandPaletteItem />
      </CommandPalettePage>
    </CommandPaletteList>
  </CommandPalette>
)
```

### useCommandPalette

Reads and changes the palette's pages from any component inside it. It returns `pages`, `activePage`, `search`, `pushPage(page)`, `popPage()` and `setPages(pages)`.

```tsx
import { useCommandPalette } from "@/components/ui/command-palette";

function OpenSettings() {
  const { pushPage } = useCommandPalette();

  return (
    <CommandPaletteItem onSelect={() => pushPage("settings")}>
      Settings
    </CommandPaletteItem>
  );
}
```

## Accessibility

The input keeps focus while you move between pages. The breadcrumb is a labelled navigation landmark that marks the current page, and opening a page announces its label to screen readers. The open and close bounce is skipped when reduced motion is preferred.
