## Layout

Import the parts, and compose them together.

```tsx
import {
  PhoneInput,
  PhoneInputLabel,
  PhoneInputGroup,
  PhoneInputCountrySelect,
  PhoneInputField,
} from "@/components/ui/phone-input";

return (
  <PhoneInput>
    <PhoneInputLabel />
    <PhoneInputGroup>
      <PhoneInputCountrySelect />
      <PhoneInputField />
    </PhoneInputGroup>
  </PhoneInput>
)
```

## Notes

- The component automatically formats and validates phone number input
- Only digits, spaces, dashes, and parentheses are allowed in the phone number field
- The full phone number (with country dial code) is submitted in forms
- Uses the Command component for country search with built-in keyboard navigation
- The country dropdown includes fuzzy search across name, dial code, and country code
- You can customize the list of countries by passing a custom `countries` prop
- The component supports both controlled and uncontrolled usage patterns
