## Usage

Wrap interactive elements to extend their clickable area:

```tsx
import { Hitbox } from "@/components/hitbox"

export function IconButton() {
  return (
    <Hitbox size="lg">
      <button className="p-1">
        <Icon className="size-4" />
      </button>
    </Hitbox>
  )
}
```

## Examples

### Custom Size

Use a custom CSS value for the hitbox size:

```tsx
<Hitbox size="20px">
  <button>Small button</button>
</Hitbox>
```

### Positional Hitbox

Apply hitbox only to specific sides:

```tsx
<Hitbox position="vertical" size="lg">
  <button>Tall target</button>
</Hitbox>
```

### Debug Mode

Visualize the hitbox area during development:

```tsx
<Hitbox debug>
  <button>Debug button</button>
</Hitbox>
```

## Accessibility

The hitbox is implemented using a CSS pseudo-element (`::after`) that extends the interactive area without affecting the visual layout or accessibility tree. Screen readers and keyboard navigation work normally.
