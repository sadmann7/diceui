## Layout

Render the skip link as the first focusable element on the page, and give your main content a matching `id`.

```tsx
import { SkipLink } from "@/components/skip-link";

<body>
  <SkipLink />
  <header>{/* Navigation */}</header>
  <main id="main-content">{/* Page content */}</main>
</body>
```

## Examples

### Custom target

Point `href` at any element on the page and change the label with `children`.

```tsx
<SkipLink href="#search">Skip to search</SkipLink>
```

### Multiple skip links

Render more than one when the page has several landmarks worth jumping to.

```tsx
<SkipLink />
<SkipLink href="#footer">Skip to footer</SkipLink>
```

## Accessibility

Skip links satisfy [WCAG 2.4.1 Bypass Blocks](https://www.w3.org/WAI/WCAG22/Understanding/bypass-blocks.html). The link stays in the accessibility tree and becomes visible when focused, so sighted keyboard users can see where it goes.

On activation, focus moves to the target element, not just the scroll position. If the target isn't focusable, it gets `tabindex="-1"` so it can receive focus, and the next <Kbd>Tab</Kbd> continues from there. The URL hash isn't changed, so the skip doesn't add a history entry.
