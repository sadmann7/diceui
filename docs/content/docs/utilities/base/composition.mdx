## Usage

### useComposedRefs

Use the hook inside components. It returns a memoized ref callback, so the ref stays stable across renders.

```tsx
import * as React from "react"
import { useComposedRefs } from "@/lib/compose-refs"

function Input({ ref, ...props }: React.ComponentProps<"input">) {
  const localRef = React.useRef<HTMLInputElement>(null)
  const composedRef = useComposedRefs(ref, localRef)

  return <input ref={composedRef} {...props} />
}
```

### composeRefs

Use the plain function outside of render, or when you can't call a hook.

```tsx
import * as React from "react"
import { composeRefs } from "@/lib/compose-refs"

function Input({ ref, ...props }: React.ComponentProps<"input">) {
  const localRef = React.useRef<HTMLInputElement>(null)

  return <input ref={composeRefs(ref, localRef)} {...props} />
}
```

Both accept callback refs and ref objects. When a callback ref returns a cleanup function, it runs on unmount.
