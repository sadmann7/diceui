## Usage

For data grid and other tablecn components, use the shadcn-style `direction` component at `@/components/ui/direction` instead — it ships automatically with those installs. This utility is for Dice UI components that depend on `@diceui/direction-provider`.

```tsx
import { DirectionProvider } from "@diceui/direction-provider"

export default function App() {
  return (
    <DirectionProvider dir="ltr">
      <YourApp />
    </DirectionProvider>
  )
}
```

### useDirection

A hook to access the current direction.

```tsx
import { useDirection } from "@/components/direction-provider"

function Component() {
  const dir = useDirection()
  
  return (
    <Button dir={dir}>
      Do a kickflip
    </Button>
  )
}
```
