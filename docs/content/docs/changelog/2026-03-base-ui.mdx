---
title: March 2026 - Base UI
description: Dice UI components now ship Base UI variants alongside Radix.
date: 2026-03-28
---

Dice UI components now ship for [Base UI](https://base-ui.com) as well as Radix UI. Each component has a Base UI page and a Radix page, and the registry serves a variant for each base.

### Base UI variants

36 components shipped Base UI variants in this release, built on `@base-ui/react` primitives. Pick the base that matches your project and install the component the same way as before.

```package-install
npx shadcn@latest add @diceui/action-bar
```

These components stayed Radix-only at launch:

- [Data Table](/docs/components/data-table) and [Data Grid](/docs/components/data-grid) gained Base UI variants in September 2026.
- [Sortable](/docs/components/sortable) and [Kanban](/docs/components/kanban) gained Base UI variants in September 2026.
- Tags Input, Combobox, Kbd, Checkbox Group, Mention, and Listbox are Radix primitives and remain Radix-only.
