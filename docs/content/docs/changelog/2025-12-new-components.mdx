We've added floating action components, dashboard indicators, and a utility for pending states.

- **Action Bar**
- **Speed Dial**
- **Gauge**
- **Status**
- **Pending**

A floating action bar that appears at the bottom or top of the viewport to display contextual actions for selected items.

A utility component that disables interactions, maintains keyboard focus, and ensures proper accessibility for buttons, forms, links, switches, and any interactive element while they are pending.
