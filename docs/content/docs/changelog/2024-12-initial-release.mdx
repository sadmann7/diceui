Dice UI launched with a set of accessible components built on Radix UI primitives. Tags Input, Combobox, Checkbox Group, and Mention also ship as `@diceui/*` npm packages.

- **Tags Input**
- **Combobox**
- **Sortable**
- **Kbd**
- **Checkbox Group**
- **Mention**

### Tags Input
