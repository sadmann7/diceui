[Data Table](/docs/components/data-table) and [Data Grid](/docs/components/data-grid) now have Base UI variants, and both run on TanStack Table v9.

Installs no longer include a manual import-path rewrite. The registry writes component, config, and type imports in place.

Column pinning state is `{ start, end }`.
