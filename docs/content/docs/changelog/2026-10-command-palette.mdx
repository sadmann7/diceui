[Command Palette](/docs/components/command-palette) is a command menu with nested pages. Items can open a page, breadcrumbs show where you are, and <Kbd>Backspace</Kbd> on an empty search goes back. It works inline or in a ⌘K dialog, and pages can load their items asynchronously.

```package-install
npx shadcn@latest add @diceui/command-palette
```
