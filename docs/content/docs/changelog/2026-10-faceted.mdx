[Faceted](/docs/components/faceted), the popover behind the [Data Table](/docs/components/data-table) and [Data Grid](/docs/components/data-grid) filters, is now its own component. It supports single or multiple selection, async search, and groups.

<ComponentTabs name="faceted-multiple-demo" />

```package-install
npx shadcn@latest add @diceui/faceted
```
