[Faceted](/docs/components/faceted) is the popover behind the data table's faceted filters. It's now its own component for both Base UI and Radix UI, so you can use it outside the data table: single or multiple selection, client-side or async search, groups, per-item counts, a clear action, and badges for the current selection in the trigger.

<ComponentTabs name="faceted-multiple-demo" />

```package-install
npx shadcn@latest add @diceui/faceted
```
