We've added ten new components, renamed two, and improved right-to-left support.

- **Scroll Spy**
- **Compare Slider**
- **FPS**
- **Tour**
- **Badge Overflow**
- **Timeline**
- **Time Picker**
- **Stat**
- **Key Value**
- **Stack**

### Renamed components

- Input Group is now [Segmented Input](/docs/components/segmented-input).
- Avatar is now [Avatar Group](/docs/components/avatar-group). The name Stack now belongs to the new [Stack](/docs/components/stack) component.

### RTL support

Components now read direction from Radix's `DirectionProvider` and `useDirection`, so every component shares one global direction context. Wrap your app in [Direction Provider](/docs/utilities/direction-provider) to switch to right-to-left.
