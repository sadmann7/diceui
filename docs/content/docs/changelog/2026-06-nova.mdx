Dice UI components now ship in the nova style alongside vega.

### Nova style

The registry serves `base-nova` and `radix-nova` variants of every component. Projects set up with the nova style get nova-styled Dice UI components with the same install command.

```package-install
npx shadcn@latest add @diceui/banner
```

The registry now resolves every official shadcn style. See the [September 2026](/docs/changelog/2026-09-presentation) update.
