We've added six new components.

- **Stepper**
- **Avatar Group**
- **Mask Input**
- **Cropper**
- **Angle Slider**
- **Circular Progress**

### Stepper

A component that guides users through a multi-step process with clear visual progress indicators.

<ComponentTabs name="stepper-demo" />

[Read the docs](/docs/components/stepper)

### Avatar Group

A component that arranges avatars with overlapping visual effects for displaying multiple users or items. It shipped as Avatar and was renamed to Avatar Group in November 2025.

<ComponentTabs name="avatar-group-demo" />

[Read the docs](/docs/components/avatar-group)

### Mask Input

An input component that formats user input with predefined patterns like phone numbers, dates, and credit cards.

<ComponentTabs name="mask-input-demo" />

[Read the docs](/docs/components/mask-input)

### Cropper

A powerful image and video cropper with zoom, rotation, and customizable crop areas.

<ComponentTabs name="cropper-demo" />

[Read the docs](/docs/components/cropper)

### Angle Slider

An interactive circular slider for selecting angles with support for single values and ranges.

<ComponentTabs name="angle-slider-demo" />

[Read the docs](/docs/components/angle-slider)

### Circular Progress

A circular progress indicator that displays completion progress in a ring format with support for indeterminate states.

[Read the docs](/docs/components/circular-progress)
