[Command Stack](/docs/components/command-stack) is a searchable command list with nested pages. Items can open a page, breadcrumbs show where you are, and <Kbd>Backspace</Kbd> on an empty search goes back. Use it inline, in a popover for nested menus, or in a dialog as a ⌘K command palette. Pages can load their items asynchronously.

```package-install
npx shadcn@latest add @diceui/command-stack
```
